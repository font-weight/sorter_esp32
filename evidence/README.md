# Подтверждения проверки от 03.10.2026

Это сохранённые результаты программных проверок и анализа файла схемы. Физическое оборудование не проверялось. PASS обозначает только указанную программную проверку. ERC схемы содержит 1 ошибку и 1 предупреждение; он не обозначен успешным.

- `test-results.json` — полный набор автономных проверок.
- `pipeline_run.json` — искусственный кадр и виртуальное движение; не результаты реальных переносов.
- `build-results.json` и `build-defaults.log` — пять исходных прошивок с выключенными аппаратными разрешениями.
- `build-hardware-paths.json` и соответствующий `.log` — три отдельные временные копии для проверки компиляции аппаратных ветвей. Их исполняемые файлы в комплект не включены.
- `hardware-symbols.json` — наличие функций камеры, UART и PWM в соответствующих ELF, с контрольными суммами; это не запуск функций на плате.
- `firmware-summary.json` — объём программ и статических глобальных переменных по отчётам линкера; пиковая RAM и PSRAM не измерялись.
- `esp32-subset-manifest.json` — официальные архивы пакетов и проверенные SHA-256.
- `schematic-current.net` и `schematic-erc.rpt` — свежий экспорт текущей схемы; исходный KiCad не изменялся.

Абсолютные временные пути в некоторых JSON описывают окружение исходной проверки. Для повторения используйте scripts и docs/build.md; временные каталоги могут быть удалены системой.
