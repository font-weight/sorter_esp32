# Проверка ESP32-CAM

Подготовленная диагностическая прошивка для Arduino-ESP32 **3.3.12**. Физическая плата не проверялась. Нужна общая библиотека `SorterCore` из `sorter/libraries`.

1. Установить пакет ESP32 и открыть `camera_diagnostic.ino`. Пример платы — **AI Thinker ESP32-CAM**, PSRAM включена. Это предположение о вашей плате, а не установленный факт.
2. Сверить маркировку и назначение выводов с `CameraBoard.h`. Только при совпадении поставить `CAMERA_PROFILE_CONFIRMED = true` в `CameraConfig.h`. По умолчанию камера не инициализируется; сведения о чипе доступны.
3. Подключить через подходящий USB-UART с логическими уровнями 3,3 В; питание платы проверить отдельно. Сервоприводы к этой прошивке не подключать. Выбор порта и загрузка выполняются вручную.
4. Открыть монитор **460800 бод**, окончание строки LF или CRLF. Выполнить `STATUS`, затем `STATS`, `TEST`. `TEST` получает до 20 свежих кадров и показывает средние RGB, доли почти чёрных/белых пикселей, контрольный отпечаток, время и свободную память.
5. `CAPTURE` предназначена для утилиты ПК: ASCII `RGB565BE 160 120 38400\n`, ровно 38400 бинарных байт, затем `\nEND\n`. Не запускать её в текстовом мониторе, если нужен читаемый вывод. Закрыть монитор перед захватом через ПК.

Каждый пиксель: **старший байт первым**, RGB565. Буфер камеры один, в PSRAM; предыдущий кадр отбрасывается, новый проверяется по времени начала съёмки. Wi-Fi и SD не используются. Подсветка GPIO4 не включается. Отсутствие PSRAM или ошибка камеры оставляют доступной USB-диагностику.

`TEST` проверяет получение кадров и их структуру. Успешные 20 кадров не доказывают точность цвета, исправность питания во время движения, фокус или калибровку. Посмотреть сохранённое изображение обязательно. Одноцветная сцена может давать одинаковые кадры без неисправности. **Для геометрической калибровки использовать CAPTURE из camera_node: там 320×240 и фиксированные настройки сенсора.**

Официальные основания реализации: [пример Espressif 3.3.12](https://github.com/espressif/arduino-esp32/blob/3.3.12/libraries/ESP32/examples/Camera/CameraWebServer/CameraWebServer.ino), [API камеры](https://github.com/espressif/esp32-camera/blob/master/driver/include/esp_camera.h), [пример распиновки AI-Thinker](https://github.com/espressif/arduino-esp32/blob/master/libraries/ESP32/examples/Camera/CameraWebServer/camera_pins.h), [порядок RGB565](https://github.com/espressif/esp32-camera/blob/master/conversions/to_bmp.c).
