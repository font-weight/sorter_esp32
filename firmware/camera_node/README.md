# ESP32-CAM

Рабочая камера финального сортировщика. Профиль AI Thinker ESP32-CAM, Arduino-ESP32 3.3.12, монитор USB 460800 бод. Межплатный UART — 115200 бод: GPIO14 RX от WROOM17, GPIO13 TX к WROOM16, общая земля.

Камера определяет красные и синие детали, переводит центры в координаты стола и отвечает по протоколу с CRC. При каждом новом кадре включает GPIO4 на время установления освещения и съёмки. Повтор того же запроса обслуживается сохранённым ответом.

`GeneratedCalibration.h` содержит принятую измеренную матрицу и область калибровки; это рабочие данные, файл удалять нельзя. `CameraConfig.h` содержит текущие RGB-пороги, ROI, фильтры, экспозицию и WB=1. Положение камеры, свет, детали и разметку сохранять прежними.

USB: STATUS и HELP; SCAN/SCAN_MM разрешаются только при отключённом межплатном UART. Обычный запуск — SORT на WROOM или кнопка GPIO18. Полная инструкция находится в корневом README.
