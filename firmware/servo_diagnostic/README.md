# Проверка SG90 по одному, без автоматического поворота

Исходная прошивка **не включает PWM**: `OUTPUTS_ENABLED=false`, `PINOUT_CONFIRMED=false`. Она подготовлена для Arduino ESP32 3.3.12 и библиотеки SorterCore. Сборка не означает, что конкретные приводы или плата физически проверены.

Программа предназначена для проверки отдельных сервоприводов со снятыми тягами и без нагрузки, а не для перемещения собранной руки. Начальная команда неизвестного SG90 может вызвать поворот: датчика текущего положения нет.

## Подготовка

1. Подтвердите модель управляющей платы и GPIO в `LocalConfig.h`. Выходы 25, 26, 27, 33 соответствуют текущей схеме KiCad (через SN74AHCT125N). Входы 32 и 23 — предлагаемое дополнение, в текущей схеме их нет; аппаратные разрешения пока оставить false.
2. Подключите один привод к отдельному проверенному питанию около 5 В с общей землёй. Остальные приводы пока не подключайте. Не подавайте силовое питание через ESP32.
3. Сделайте физическое отключение питания привода. Вход ENABLE получает 3,3 В только при разрешении; LOW или обрыв запрещает движение. POWER_GOOD должен приходить от согласованной с 3,3 В схемы контроля силового питания. **Подавать силовые 5 В прямо на GPIO запрещено.**
4. Оставьте узкий исходный диапазон 1400–1600 мкс. Он не является механической калибровкой. Для конкретного экземпляра при необходимости сначала уточните допустимые сигналы по его документации; при отсутствии сведений держите тяги снятыми и питание доступным для немедленного отключения.
5. После проверки подключения установите два разрешающих флага в true и соберите прошивку. При старте всё равно ни один PWM не включается.

## Команды USB-консоли

Скорость 115200, команды завершаются переводом строки.

| Команда | Результат |
|---|---|
| `HELP`, `STATUS` | Помощь, выбранный канал, текущая/целевая длительность импульса |
| `ARM 0 1500` | Подключить **только** канал 0 и явно задать начальные 1500 мкс; разрешены индексы 0–3 |
| `US 1510` | Медленно изменить команду до 1510 мкс; одна команда меняет не более чем на 25 мкс от текущего значения |
| `DISARM` | Отключить выбранный PWM |
| `ESTOP` | Отключить PWM и зафиксировать ошибку |
| `RESET` | Сбросить ошибку в отключённом состоянии; сам привод не запускается |

Выход обновляется раз в 20 мс, скорость изменения ограничена 100 мкс/с. Первая команда ARM задаёт исходный импульс сразу, поэтому **не гарантирует плавного старта из неизвестного физического угла**. Автоматического sweep, широкого поворота и запуска всех четырёх каналов нет.

После 10 секунд без новой команды ARM/US выход отключается. Команды STATUS не продлевают удержание. Это ограничение предназначено для ненагруженной диагностики: собранную руку нельзя оставлять без опоры в ожидании отключения.

При исчезновении ENABLE/POWER_GOOD, ошибке настройки PWM или задержке цикла свыше 250 мс возникает фиксируемая остановка. Возвращение питания ничего не запускает: восстановите условия, выполните RESET и новый ARM. Спад входа дополнительно фиксируется обработчиком прерывания; это не заменяет аппаратного выключателя силовой цепи.

## Какие данные записать

Для каждого экземпляра: маркировка, устойчивое питание без/под нагрузкой, ток холостого хода и удержания без упора, реакция на 1400/1500/1600 мкс, люфт, шум, нагрев и диапазон без механического упора. Перед сменой привода выполняйте DISARM и снимайте питание.

Затем отдельно определите пределы **в собранной механике**. Предел свободного сервопривода нельзя напрямую считать пределом звена MeArm. Уменьшайте диапазон при натяжении тяги, упоре губок или заметном росте тока. До установки тяг сохраните найденную центральную позицию и правильно ориентируйте качалку.

Программа не измеряет ток, напряжение, температуру или фактический угол: значения необходимо получить внешними приборами. `STATUS us=...` — это программная команда PWM.

API PWM: [официальная документация Arduino ESP32 LEDC](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/ledc.html).
