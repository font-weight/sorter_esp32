# Калибровка камеры и проверка координат

Цель — связать центр детали на изображении `(u, v)` с реальными координатами `(x, y)` в миллиметрах. Алгоритм ниже даёт плоскую гомографию. Он не измеряет люфт SG90, положение осей руки, высоту детали или искажение линзы. Эти ошибки проверяются отдельно.

## 1. Зафиксировать условия

Камера закреплена над рабочим полем и не движется с рукой. Стойка, фокусировка, разрешение, обрезка кадра, зеркальность и ориентация изображения после калибровки не меняются. Перемещение камеры, переключение `hmirror`/`vflip` или разрешения требует новой калибровки.

Рабочий профиль использует 320×240. Снимок для координат берётся именно в этом режиме. Изображение 160×120 из первичной диагностики пригодно для проверки изображения, но не для непосредственного переноса его пиксельных координат в рабочую прошивку.

Предметы первой версии должны быть одинаковой высоты и иметь доступный для распознавания центр. Для круглых цилиндров камера находит центр их верхней поверхности. Поэтому центры калибровочных меток располагаются **на той же высоте**, а не автоматически на плоскости стола. Например, при видимой верхней поверхности на высоте 10 мм метки закрепляют на плоской опоре той же высоты; фактическую высоту измеряют и записывают. Пример 10 мм не является измерением ваших деталей.

## 2. Определить систему координат

Начало и направления X/Y нужно согласовать с геометрией управляющей прошивки. Положительное направление каждой оси отметьте стрелкой на основании. Запишите расстояния относительно фиксированной механической точки, а не относительно случайного угла фотографии. Точки для камеры и точки для руки должны описывать одну систему координат.

До механического движения проверьте знаки: предмет справа/слева и ближе/дальше должен давать ожидаемое изменение X/Y. Нельзя устранять ошибку знака поворотом изображения без повторной калибровки.

## 3. Собрать две группы точек

Разместите 9 обучающих меток сеткой 3×3 на безопасной рабочей области, включая её углы. Независимо разместите ещё 4 контрольные метки между ними. Координаты контрольных меток не должны повторять координаты обучающих. Не располагайте все точки на одной прямой или в узкой полосе.

Снимите метки при рабочем освещении. В редакторе изображения определите координаты центров в исходном разрешении: U растёт вправо, V вниз. Измерьте реальные X/Y каждой метки линейкой или другим доступным способом с известной погрешностью. Если цена деления линейки и размытый центр уже дают несколько миллиметров ошибки, инструмент калибровки не сможет исправить качество исходного измерения.

CSV содержит столбцы `split,u,v,x_mm,y_mm`. `train` означает точку для расчёта, `test` — точку только для проверки. Минимум инструмента — 6 обучающих и 3 контрольные точки; рабочая рекомендация — 9+4. Не меняйте метку `test` на `train` только для улучшения отчётной ошибки. Для переработанной калибровки после подбора условий соберите новый независимый контрольный набор.

## 4. Рассчитать преобразование

Команда приведена в `tools/README.md`. Укажите `--provenance measured` только для фактически измеренных точек. Без этого калибровка остаётся `unverified`. Флаг не делает измерения достоверными сам по себе.

Нормализованный DLT сначала переносит обе группы координат к их центрам и приводит среднее расстояние к √2. Затем по обучающим соответствиям методом SVD находится матрица H. Для каждой новой точки вычисляется:

```text
w = h20*u + h21*v + h22
x = (h00*u + h01*v + h02) / w
y = (h10*u + h11*v + h12) / w
```

Программа отвергает повторные точки, вырожденное или почти вырожденное размещение, выход точек за кадр и пересечение области поддержки проективным горизонтом. Ошибка — евклидово расстояние в миллиметрах между предсказанием и измеренной контрольной координатой. Отдельно выводятся среднее, RMS, P95 и максимум для `train` и `test`.

Минимальная ошибка на обучении ещё ничего не доказывает. Решение об использовании принимается по независимым контрольным точкам, а затем по физической проверке. Предварительный порог максимальной ошибки 2 мм можно сделать строже; его нужно сопоставить с размером детали, раскрытием губок и разбросом механики. Систематически растущая ошибка у края может означать заметную дисторсию объектива: сократите рабочую область и повторите измерения либо добавьте отдельную коррекцию линзы в дальнейшей версии. Текущая прошивка такую коррекцию не выполняет.

## 5. Ограничить область применения

Гомография не даёт доказанной точности за пределами обучающих меток. В JSON и заголовок записывается выпуклая оболочка их пиксельных координат. Можно выбрать вписанный прямоугольник `--valid-rect U0 V0 U1 V1`. Контрольные точки должны находиться в выбранной области; углы прямоугольника — внутри обучающей оболочки. Максимум поддерживается 16 вершин.

Внешняя граница камеры, допустимая область гомографии и достижимая область руки — разные ограничения. Объект должен пройти все проверки. Область камеры не должна автоматически становиться разрешением для руки двигаться в любую её точку. Для захвата также нужен запас до соседней детали и до края поля.

## 6. Проверить перенос данных в прошивку

`GeneratedCalibration.h` содержит namespace `sorter_calibration`, `CALIBRATION_ID`, `IMAGE_WIDTH`, `IMAGE_HEIGHT`, `HOMOGRAPHY[9]`, `SUPPORT_COUNT` и `SUPPORT`. Тип точки берётся из `<Homography.h>`. Матрица хранится построчно. Ненулевой идентификатор по умолчанию вычисляется из параметров калибровки; его можно задать через `--calibration-id`. При изменении калибровки меняйте идентификатор и на управляющей плате, чтобы старые координаты не принимались в новой сессии.

Генератор никогда не включает `CALIBRATION_CONFIRMED`: по умолчанию он `false`. До подтверждения должны быть проверены происхождение данных, разрешение, ориентация, единицы, направление осей, высота и независимая ошибка. Синтетическую матрицу подтверждать для физической работы нельзя. Готовый заголовок сначала сохраняется в `output`, а не автоматически подменяет конфигурацию прошивки.

## 7. Проверить реальный стенд по частям

Сначала при отключённых приводах положите деталь в несколько измеренных точек: центр, ближние/дальние участки и края допустимой области. Сравните координаты камеры с измерениями; запишите результаты. Затем отдельно проверьте повторяемость руки между фиксированными точками без камеры. Только после этого соединяйте два результата в захват.

Полезная запись испытания: заданные X/Y, координаты камеры, фактическое положение центра губок, номер повтора, направление подхода, нагрузка и исход. Ошибка полного переноса складывается из ошибки камеры, измерения, кинематики, нулей сервоприводов, люфтов и деформации. Уменьшение ошибки H не заменяет устранение люфта или неверной геометрии.

Результат этой процедуры — подтверждённая калибровка конкретной установки и журнал измерений. Сейчас в комплекте есть только программная реализация и искусственные данные для её проверки.
