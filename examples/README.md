# Только искусственные примеры

Все файлы с префиксом `synthetic_`, а также `SyntheticCalibration.h`, созданы программно. Камера не использовалась, робот не выполнял переносы. Эти результаты нельзя включать в отчёт как экспериментальную точность или успешность стенда.

Сцена `synthetic_scene.png` содержит четыре раздельных круга: два красных, один зелёный и один синий. Повтор красного цвета нужен для проверки разделения отдельных объектов одного класса. Эквивалентные данные есть в PPM и RGB565BE. Истинные центры и искусственная матрица записаны в `synthetic_scene_truth.json`; центр реального цветового пятна камеры может отличаться из-за освещения и оптики.

`synthetic_calibration_points.csv` содержит девять обучающих и четыре независимые контрольные точки с небольшой заранее заданной искусственной погрешностью. `synthetic_calibration_layout.png` показывает их размещение. JSON содержит численные ошибки, но всегда оставляет `calibration_confirmed=false`.

`synthetic_run.csv` специально включает неудачи. Восемь испытаний, девять попыток, три успеха с первой попытки и четыре итоговых успеха после возможного повтора — проверочные числа для инструмента статистики.

`protocol_vectors.json` — эталонные строки UART, пригодные для проверки совпадения C++ и Python. CRC для ASCII `123456789` должен быть `29B1`.

`calibration_points_template.csv` и `run_log_template.csv` пустые. Скопируйте их в собственный каталог измерений и заполняйте реальными данными. Синтетические строки из остальных файлов переносить в измеренные журналы нельзя.
